# My AI-Assisted Interactive Portfolio Website

Welcome to my first open-source project! I built this interactive single-page portfolio website using code and AI tools.

## 🚀 Live Site
* Check out the live deployment here: [https://netlify.app](https://netlify.app)

## 🛠️ Tech Stack & Features
- **HTML5:** Page structures, layout nodes, and text elements.
- **CSS3:** Clean visual typography, layout cards, and border styling.
- **JavaScript:** Client-side functionality for interactive triggers.
- **Full-Stack Database:** Fully operational Netlify serverless forms to collect contact messages.
- **Interactive Component:** Custom written toggle logic switch supporting a sleek Dark Mode scheme.

## 💻 Running the Project Locally
1. Clone or download this repository.
2. Ensure your profile image file is named `avatar.png` and sits in the same directory as `index.html`.
3. Open `index.html` in any standard web browser.
